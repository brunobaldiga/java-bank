# Java Bank

A banking application built with Java 21 to practice and reinforce core Java concepts, object-oriented programming, and software design.

The core banking logic has been implemented and manually tested. The project currently runs as a console application and will be developed into a JavaFX desktop application in the future.

## Technologies

- Java 21
- Maven
- PostgreSQL
- JPA / Hibernate
- HikariCP
- Flyway
- Docker Compose

## Features

- Checking and savings accounts
- Account authentication
- Deposits and withdrawals
- Transfers between accounts
- Overdraft management
- Savings interest calculations
- PostgreSQL persistence

## Project Status

**In Development**

Core banking functionality implemented and manually tested. JavaFX graphical interface planned.
